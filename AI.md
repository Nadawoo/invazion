# Usage of AI in this project

## General principle
Most of the content in this project, including code and graphical assets, is created by humans. Although AI can be an invaluable tool for reducing the workload involved in a project like this, we deliberately use it sparingly and only when it provides clear value.

In some cases, we may use AI as described below.

## AI-assisted use cases
AI may be used as an assistance tool to support human work, for example:
* Assisting with coding (debugging, generating small technical code snippets, etc.)
* Improving the quality of human-written code (applying best practices, suggesting performance improvements, identifying potential issues, etc.)
* Assisting with design discussions (technical architecture, game design, and similar topics)

As far as possible, AI is not used for trivial or general questions that can easily be answered through a web search.

## Rare AI-generated code
In very rare cases, AI may be used to generate generic algorithms (for example, pathfinding). Whenever a significant portion of the code is primarily generated by AI, it is explicitly identified with comments in the source code. All AI-generated code is reviewed by a human and modified when necessary before being included in the project.

To give an idea of ​​how rare it is, at the time of writing (2026) the entire codebase contains only two AI-generated snippets.

## Where AI is never used
AI is NOT used to generate any images or other artistic assets included in this project.

AI is NOT used in gameplay mechanics (such as generating dialogue or controlling units). No AI services are invoked while playing the game.

AI is NOT used in any automated development or deployment process (such as automated commits, code generation pipelines, or deployment workflows).

No personal data (e.g. email addresses or usernames) is transmitted to AI services.
