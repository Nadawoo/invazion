# Usage and non-usage of AI in this project

## General principle
Most of the content in this project, including code and graphical assets, is created by humans. Although AI can be an invaluable tool for reducing the workload involved in a project like this, we deliberately use it sparingly and only when it provides clear value.

## Where AI is never used
* AI is NOT used to generate any images or other artistic assets included in this project.
* AI is NOT used for automated code generation.
* AI is NOT used for automated deployment.
* AI is NOT used in gameplay mechanics, such as generating dialogue or controlling units. No AI services are invoked while playing the game.
* No personal data (e.g. email addresses or usernames) is transmitted to AI services.

## AI-assisted use cases
AI may be used occasionally to assist human developers:
* Helping investigate complex bugs
* Suggesting security or performance improvements
* Discussing code architecture or best practices
* Exploring specific game design questions

As far as possible, AI is not used for trivial or general questions that can easily be answered through a web search.

## Rare AI-generated code
In very rare cases, AI may be used to generate common algorithms (for example, pathfinding).

Whenever a substantial portion of the code is generated by AI, it is explicitly identified with comments in the source code.

All AI-generated code is reviewed by a human and modified when necessary before being included in the project.

At the time of writing (2026), the entire codebase contains only two AI-generated snippets.
